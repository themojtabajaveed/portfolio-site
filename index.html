01 — About

Less chasing. More accounting.

Small accountancy practices lose days every month asking clients for bank statements, invoices and receipts. I build AI agents that take that work on: document intake, LLM extraction, checklist logic and chase automation, with the accountant approving every message before it goes out.

Every agent keeps an audit log and is measured against a labelled eval set, so you can see what it got right, what it missed and why. Built with Python, n8n, RAG and LLM APIs. Recent B.Tech grad (CSE — AI & ML).

Less interested in demos, more interested in what gets shipped. Open to pilot projects with UK practices, and to AI automation and agent engineering roles.

02 — Selected Work

What I'm building.

Flagship project in progress, built in public. Demo data is synthetic and labelled as such.

/ 01

Missing-Docs Agent — for UK accountancy practices

Client uploads statements and invoices. The agent classifies and extracts them, checks them against what that client type needs, flags what is missing, and drafts a specific chase email. The accountant approves in one click, then reminders run on day 3, 7 and 14. Dashboard and audit log included, with accuracy measured on an eval set. Runs on Companies House data, public HMRC guidance and synthetic client documents.
